Use esta tela para organizar os códigos que clientes ou fornecedores usam para identificar uma peça. A referência pode ser diferente do código interno do catálogo.

### Incluir uma referência

Escolha **Cliente** ou **Fornecedor**, informe o contato e digite o código. Clique em **Adicionar** e confira se a referência apareceu na lista. Para corrigir uma entrada, remova-a na linha correspondente.

Use **Cancelar** para voltar. Nesta versão, a lista fica apenas na tela: adicionar uma referência aqui ainda não cria um vínculo salvo com a peça.
