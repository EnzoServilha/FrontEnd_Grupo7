Use esta tela para incluir uma peça no catálogo. O formulário tem três etapas: **Informações Gerais**, **Códigos Associados** e **Assimilar Peças**.

### Preencher o cadastro

Em **Informações Gerais**, informe o **código interno**, que é obrigatório. Complete ano, marca, localização e descrição conforme os dados disponíveis. A localização ajuda quem precisar encontrar a peça no estoque.

Use **Códigos Associados** para montar uma lista de referências usadas por clientes ou fornecedores. Em **Assimilar Peças**, você pode listar códigos de itens similares. Confirme a compatibilidade antes de usar um item como substituto.

Revise os dados e clique em **Cadastrar**. Se quiser sair sem enviar, use **Cancelar**. Nesta versão, somente as **informações gerais** são salvas; os vínculos com códigos e peças similares ainda não são gravados pelo formulário.
