Use esta tela para incluir uma pessoa ou empresa na lista de **Clientes**.

### Preencher o cadastro

Em **Informações Gerais**, escolha o tipo de cliente e preencha os dados de identificação e contato, como nome, documento, telefone e e-mail. Use o campo de observações para registrar informações que ajudem no atendimento.

Avance para **Endereço** e complete os dados disponíveis, como CEP, cidade, logradouro e número. Você pode voltar à primeira etapa para corrigir os dados antes de clicar em **Cadastrar**. Use **Cancelar** para sair sem concluir.

Nesta versão, o cliente aparece na listagem da interface; o cadastro ainda não é salvo no servidor.
