Use esta tela para organizar referências de peças similares a um item do catálogo.

### Incluir uma peça similar

Informe o **código interno** da peça e clique em **Adicionar**. Confira a lista e, se incluiu um código incorreto, remova-o na linha correspondente. Antes de usar uma peça como substituta, confirme se ela é compatível com a aplicação.

Use **Cancelar** para voltar. Nesta versão, a tela ainda não verifica os códigos no catálogo nem salva os vínculos.
